## SimuCUBE 2 Pro 설정

### Porsche 911 GT3 R 프로파일

```
Overall Strength: 50% (= 12.5Nm)
Reconstruction Filter: 3
Damping: 4%
Friction: 0%
Inertia: 0%
Slew Rate Limit: Disabled
Wheel Range: 540도
Center Spring: 0%
```

### 설치 순서
1. USB 연결 (PC 뒷면 직접)
2. Tuner 3.0 실행 → 펌웨어 업데이트
3. E-Stop 연결 확인
4. High Torque Mode 활성화 (10초 카운트다운)
5. 센터 캘리브레이션 → "Set permanent wheel center"
6. FFB 프로파일 생성

### LMU 진동 이슈 해결
1. **True Drive → Ultra Low Latency OFF** (가장 간단)
2. **lmuffb 앱** (https://github.com/coasting-nc/LMUFFB)
3. 인게임 FFB Smoothing 5~7 (최후 수단)

**답력**: 13kg (최소) ~ 45kg (최대)

- ✅ TC

### mBooster 상세 사양

| 항목 | 값 |
|---|---|
| 브레이크 힘 설정 | 30~200kg (데드존 0~30kg 조절) |
| 브레이크 유효 스트로크 | 4.3~32.1mm (시작/끝점 3.8~49.7mm 내) |
| 스로틀/클러치 | travel 10.7~45.9mm, 힘 4~20kg |
| 치수 (W×H×D) | 90 × 234 × 382.5mm |
| 전력 | 270W peak, 110~220V AC → 48V DC |

| 보증 | 24개월 |

**게임 호환성**: LMU에서 ABS 진동 정상 작동 확인 (2026.10.15). 리뷰상 rFactor 2 미작동으로 알려졌으나 LMU는 별도 지원됨. iRacing은 ABS만 지원, 락업 텔레메트리 미지원.

## 페달 비교 — mBooster vs Simucube ActivePedal (2026.10.15)

> Simucube가 2026.10.13 **ActivePedal Sport** 공개, 2027년 초 출시 예정.

| 항목 | mBooster (보유) | AP Sport | AP Pro | AP Ultimate |
|---|---|---|---|---|
| 최대 힘 | 200kg (설정 30~200, 액추에이터 실출력 미공개) | 100kg (설정 상한) | 110kg | 170kg |
| 유효 스트로크 | 32.1mm | 60mm | 74mm | 79mm |
| 본체 길이 | 382.5mm | **250mm** | 418mm | 402mm |
| 무게 | 미공개 | 3.4kg | 5.8kg | — |
| 전력 | 270W | 280W | 280W | — |
| 높이/각도 조절 | 각도 15° | 20mm / 18° | 22mm / 18° | — |
| 햅틱 | 8종 | 7종 | 동일 계열 | 동일 계열 |
| 보증 | 24개월 | 36개월 | 36개월 | 36개월 |
| 가격(세금별도) | $759~799 / €899 | $1,199 / €901 | 약 £1,554 (Hub 포함) | — |
| 세트 | +CRP2 세트 $999 | +Co-Pedal+Link Hub $1,798 | — | — |

**Sport 제약**: Link Hub 필수(미포함), **데이지 체인 불가**(리그당 Hub 1개 공유), 2027년 초 출시.

**리뷰 평가 요약**
- mBooster 우위: 가격 절반, 200kg 로드셀 고압 표현, 튜닝 폭(프리셋 15종), MOZA 생태계 통합
- Simucube 우위: 햅틱이 선명하고 요청 강도를 정확히 출력. mBooster는 "뭉개짐(muddier)·계단식(stepped)" 지적

**결론: 교체 보류.** 실익이 스트로크 1.9배 + 크기 132mm 단축 + 햅틱 선명도뿐이라 비용 대비 과함. 우선순위는 9800X3D CPU 업그레이드.
